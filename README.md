# Maneviyat

Namaz vakitleri, Kur'an-ı Kerîm, zikirmatik, dualar, kıssalar, hadisler ve ilmihal.
Ücretsiz, reklamsız; internet olmadan da çalışır.

**Uygulamayı aç:** https://ysnbilici06.github.io/Maneviyat/

- iPhone / iPad: Safari ile aç → Paylaş → **Ana Ekrana Ekle**
- Android: Chrome ile aç → ⋮ menü → **Uygulamayı yükle**

Kullanıcı verileri (namaz kayıtları, dualar, günlük) yalnızca cihazda tutulur; hiçbir sunucuya gönderilmez.

## Kaynaklar
Arapça metin: Tanzil Projesi (tanzil.net, değiştirilmeden). Meal: Diyanet İşleri Başkanlığı.
Okunuş: Muhammet Abay (alquran.cloud). Sesli okuma: Mişâri Râşid el-Afâsî (islamic.network).
Yazı tipleri: Amiri Quran ve Cormorant Garamond (SIL Open Font License, `fonts/`).
